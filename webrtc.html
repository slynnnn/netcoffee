WebRTC 泄露检测

WebRTC 建立点对点连接时会通过 STUN 服务器发现你的外网 IP，这个过程走 UDP。很多代理只处理 TCP，于是 STUN 可能绕过代理，直接暴露真实 IP。本页同时向多个公共 STUN 服务器发请求，收集所有返回的 IP 并与你的出口 IP 对比。

注意模式差异：系统代理模式下 STUN 的 UDP 发不出去，显示“无泄露”可能是假象；TUN 模式下 UDP 能发出，结果才真实反映 UDP 出口。多个不同 IP 不一定是泄露——分流规则本来就可能把不同 STUN 服务器路由到不同出口；只有当 STUN 返回的是你本地运营商 IP、而你本应走代理时，才是真泄露。

发现泄露怎么办（简述）

  • Firefox：about:config 里把 media.peerconnection.enabled 设为 false。
  • Chrome / Edge：用 uBlock Origin 的“阻止 WebRTC 泄露本地 IP”选项。
  • Brave：隐私设置里选“禁用非代理 UDP”。
  • 进阶：代理客户端里对 STUN 流量单独做 UDP 分流，走代理出口。
