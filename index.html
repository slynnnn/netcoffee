我的 IP 查询

查看当前 IP 地址、地理位置、网络连通性和分流出口。分流出口的含义见下方说明：浏览器本身看不到每个网站背后的出口 IP，只能通过延迟/可达性差异推断路由。

诚实说明：所谓“每个网站的出口 IP”，只有在你自己的代理/服务器上做出口探测才能逐站拿到。本页在浏览器里做的是：显示你的当前出口 IP，并逐站测延迟与可达性；若某站走了不同线路，延迟和地区表现会明显不同。点下方表格里的 IP，会跳到 IP 评分页做进一步查询。

分流出口汇总

按国内 / 国际分组，再按类别分组。点击 IP 列的地址可到 IP 评分页查询该 IP（当前页只能填入你自己的 IP 做示例；逐站出口 IP 需后端探测，见 README）。

本页能做什么、不能做什么

  • 能：查你当前出口 IP、归属、ISP、类型；测各站延迟，验证分流是否按预期生效。
  • 不能：直接读出每个网站的出口 IP、也不能替你改代理规则。需要逐站出口 IP 时，请用你自己的出口服务器做探测，或接入 README 里写的后端探测接口。
