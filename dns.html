DNS 泄露检测

DNS 泄露的意思是：流量走了代理，但 DNS 查询还走了本地运营商，于是对方能看到你查过哪些域名。真正“看到你系统 DNS 出口”的检测，需要自建权威 DNS + 唯一子域名记录查询来源，本页浏览器版做不到这一点，因此下面是诚实的两部分：

浏览器版能做的：测你到各公共 DoH 解析器的延迟与解析结果，并对比你的出口 IP 地区；不能做的：直接读出你系统 DNS 的出口 IP。要后者，请按 README 部署权威 DNS 探针，或用你信任的第三方泄露测试站交叉验证。

简短自查指南（本站原创）

  • 开了代理后，确认代理客户端接管了 DNS：开启 fake-ip / DNS 劫持，或用 TUN 模式让 UDP 也走代理。
  • 浏览器里关掉“安全 DNS / DoH”绕过代理的情况（除非你有意让浏览器自己走 DoH），否则 DNS 可能不走代理通道。
  • 只处理 IPv4 不够：IPv6 的 AAAA 查询也可能绕过代理，代理场景下可考虑关 IPv6 再测。
  • 改完后回本页重测，并到 WebRTC 页再查一次 UDP 泄露。

DoH 与 DoT 的区别：普通 DNS 明文；DoT 用 853 端口 TLS 加密但特征明显；DoH 藏在 443 的 HTTPS 里最隐蔽。隐私最好的是 DoH，但前提是它走你信任的通道。
